# 踩过的坑

按主题合并，只记技术结论。

## 运行库与打包

- Homebrew 的 FFmpeg/WebP 最低系统版本是 macOS 26，不能用于 macOS 13 目标。现在用固定哈希的静态 arm64 FFmpeg 9.0.2（最低 12）和 Pillow wheel 里的 libwebp（最低 11），不改 Mach-O 版本号。
- 打包后的 App 只认随包运行库；开发回退路径只在 .app 之外生效，否则缺库会被系统里的旧版本悄悄掩盖。
- 随包 Python 必须禁止写字节码（`PYTHONDONTWRITEBYTECODE=1`），否则首次 import 会往签了名的 App 里写 `__pycache__`，签名失效。构建签名前也清理一次。
- libwebp 原文件只读，重复构建前要先 `chmod u+w`；改 install_name 后要重新签名。
- 随包 LibreOffice 的 Fontconfig 默认不扫描 macOS 字体，中文 PDF 会变空白。每个任务在临时目录写 FONTCONFIG_FILE，列出随包和系统字体目录，缓存也放临时目录。
- 官方 LibreOffice 26.2.6 用本机 unix socket 做进程通信。`sandbox-exec` 的 `(deny network*)` 会把这种 socket 一起禁掉，soffice 随即以退出码 0 结束且不生成文件。离线验收仍拒绝 TCP，只放行 unix socket。
- 只检查"PDF 存在、页数对、英文能提取"会漏掉中文丢失；内容必须独立回读。

## 子进程

- 父进程退出不代表子进程都退出了。取消、超时和正常结束后，都要清理已确认属于本任务的进程组。
- 捕获 TERM 后返回 0 的进程，超时了仍按失败处理。
- LibreOffice 用错 TXT 过滤器时会生成超大临时文件；现在改走 DOCX XML 文字导出，并限制 CPU、文件大小和时长。

## Office / PDF / Pages

- 直接用 AppleScript 打开临时 DOCX 会被 Pages 沙箱拒绝；用 LaunchServices 打开本任务的 UUID 副本才行。只关闭本任务的文稿，不退出 Pages。
- Pages 偶发错误 609（断连）：先回读本任务暂存结果是否已完整，再有限重连，不重复导出。取消后的清理用独立的短超时。
- PDFKit/pypdf 的文字流顺序和连字可能出错；判断内容要用独立的布局提取器加页面渲染复核。中文顺序只在去空白后字符集合完全一致时才纠正。
- 生产 PDF 路由走 OfficeEngine；排查问题先看 EngineRouter，别被没用到的旧代码路径误导。
- PDF 旋转预览要在 PDFPage 副本上设 rotation 再出缩略图；导出用绝对旋转参数。
- CSV 解析启用 strict，未闭合的引号直接报错。

## 媒体与图片

- 单帧 GIF 没有时长，按 1 秒处理；动画 GIF 用 10ms 时间栅格保留帧延时。
- SVG 转 WebP 不能假设 FFmpeg 带 libwebp，统一走原生编码。
- 视频裁切按比例换算后要先稳定像素边界再做偶数对齐，否则会少 2 像素。
- 编辑图片指定精确尺寸时，调色之后还要按目标宽高重采样。
- macOS 编码和 textutil 依赖系统服务，在受限沙箱里 HEIC/textutil 可能失败。

## 界面

- 轮盘命中区域曾错开半个扇区；改动轮盘几何后要检查各扇区中心和两侧。
- 2026-10-29 起产品不再提供 Control 操作轮盘，也不再提供那六项文件操作。不要把它们接回拖放或主界面。
- 桌面轮盘的松手不能只看左键：macOS 把按住 Control 的点击当成右键，拖放来源在按住 Control 时只允许 link、按住 Command 时只允许 generic。现在任一键按下都算拖动中，连续两次轮询无按键才算松手，另有鼠标松开事件做后备，拖放目标按来源允许的操作回应。Control 松开后会话按键位可能一直为 1；这时不能清掉「见过硬件按下」，否则下一拍会当成新的拖动。`hide()` 只 `orderOut` 时面板会留在屏幕上，格子已空，显示「没有可用选项」，而 `shown` 已是 false，Esc 不再处理。隐藏时要把面板移出屏幕。复制路径和另外五项文件操作已经从产品拿掉，不要再为剪贴板改写把它们接回来。改松手或 Esc 要跑 native-drop。物理手势仍要人在 Mac 上试，而且不要把已经拿掉的 Control 操作记成通过。
- 系统拖动剪贴板会保留上一次的数据；只有本次鼠标按下期间剪贴板有变化才弹轮盘。不同 App 提供拖动数据的时机不一样，需要实机验证。
- 物理 Finder"按住修饰键拖动"目前没有自动化手段验证，落点集成测试不等于物理手势通过。
- `tools/verify_release.sh` 末尾的覆盖数要和套件一起改。删除缩放和旋转后回归是 58 项；加上任务排队后，原生界面是 31 项。只改测试不改这个数字时，前面的阶段都会通过，完成证书仍然不会生成。
- 损坏文件的底层长日志不能铺满窗口：任务栏只显示简短提示，完整诊断折叠显示。
- 编辑面板打开时截图测试无法退出，要先关面板；视频暂停预览用已解码的封面帧，避免离屏 GPU 黑帧。
